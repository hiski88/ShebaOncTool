# ShebaOncTool

פרוטוטייפ Streamlit לתכנון לוז מתמחים באונקולוגיה.

## מה כלול בגרסה הראשונה

### 1. תכנון העדפות אישיות

- בחירת חודש ושנה.
- טבלה מצומצמת עם תאריך, יום וחג או יום מיוחד.
- סימון אי זמינות, חופש והערה.
- הפקת פלט מובנה להעתקה.
- הורדת קובץ Excel אישי.

### 2. ריכוז העדפות ובניית לוז

- הורדת קובץ תבנית שבו מדביקים את כל תשובות הצוות.
- העלאת קובץ הריכוז.
- בנייה אוטומטית של טבלת זמינות לפי תאריך ועובד.
- סיכום מספר הימים הלא זמינים וימי החופש.
- הורדת תבנית לוז אונקולוגיה עם חגים שמוזנים אוטומטית.
- אפשרות להעלות תבנית לוז קיימת מסוג XLSX ולהוסיף לה את גיליונות הזמינות והסיכום.

### 3. לוז סופי ויומן

- העלאת XLS או XLSX.
- זיהוי אוטומטי של שמות אפשריים.
- זיהוי שם מחוק והפרדה בין העובד המקורי לעובד בפועל.
- פירוש א"ת כאחרי תורנות.
- הבחנה בין מחלקה ביום רגיל, ביקור שישי, מחלקה בסוף שבוע, תורנות שישי ותורנות שבת.
- פענוח מיון אונקולוגי, אשפוז יום, אבחון מהיר, תגבור מיון, מרפאות, כוננויות ותורנויות.
- טבלת סיכום מטלות אוטומטית לפי עובד.
- בדיקות איוש אוטומטיות: 3 עובדים במחלקה ביום רגיל, 2 ביום שישי ו-2 בשבת.
- הורדת קובץ ICS.
- חיבור OAuth ליומן Google ויצירת אירועים ישירות לאחר תצוגה מקדימה ואישור.

## התחלה מהירה לפרסום

לאחר הורדת חבילת הפרויקט ב-Windows אפשר לפרסם אותה למאגר הקיים באמצעות:

```powershell
powershell -ExecutionPolicy Bypass -File .\PUBLISH_TO_GITHUB.ps1
```

להרצה מקומית:

```powershell
powershell -ExecutionPolicy Bypass -File .\RUN_LOCAL.ps1
```

הסבר מלא נמצא בקובץ `DEPLOYMENT_HE.md`.

## פריסה ב-Streamlit Community Cloud

1. נכנסים ל-https://share.streamlit.io
2. בוחרים Create app.
3. בוחרים את המאגר `hiski88/ShebaOncTool`.
4. בוחרים branch בשם `main`.
5. מגדירים Main file path כ-`app.py`.
6. מבצעים Deploy.

לאחר החיבור הראשוני, כל עדכון ל-branch הראשי ב-GitHub יפעיל פריסה מחדש של האפליקציה.

## הגדרת Google Calendar

1. יוצרים Project ב-Google Cloud Console.
2. מפעילים את Google Calendar API.
3. מגדירים OAuth consent screen.
4. יוצרים OAuth Client מסוג Web application.
5. מוסיפים Authorized redirect URI זהה בדיוק לכתובת אפליקציית Streamlit.
6. מוסיפים ב-Streamlit App Settings את הסודות הבאים:

```toml
[google_oauth]
client_id = "YOUR_GOOGLE_OAUTH_CLIENT_ID"
client_secret = "YOUR_GOOGLE_OAUTH_CLIENT_SECRET"
redirect_uri = "https://YOUR-APP.streamlit.app"
```

האפליקציה מבקשת רק הרשאת עריכת אירועים והרשאת קריאת רשימת היומנים, ולא הרשאה מלאה למחיקת יומנים או לשיתוף שלהם. אסימוני ההתחברות נשמרים רק ב-session של המשתמש ואינם נכתבים ל-GitHub.

## פרטיות

המאגר ציבורי ולכן אסור להעלות אליו:

- לוחות עבודה אמיתיים
- שמות עובדים
- נתוני זמינות
- קובצי XLS או XLSX מהמחלקה
- Google client secret
- אסימוני OAuth

הקבצים שמועלים באפליקציה מעובדים בזיכרון ומוחזרים כקובץ להורדה. הקוד אינו שומר אותם במאגר.

## הנחות שדורשות אימות לפני שימוש שוטף

- פעילויות יום נוצרות ביומן כאירועי יום שלם.
- תורנות אשפוז יום מוגדרת כברירת מחדל 16:00 עד 21:00.
- תורנות מיון מוגדרת 16:00 עד 08:00 למחרת.
- תורנות מחלקה רגילה מוגדרת 16:00 עד 10:00 למחרת.
- תורנות שישי ותורנות שבת מוגדרות 08:00 עד 10:00 למחרת.
- תורנות שבת מתחילה בשבת ואינה כוללת את שישי בבוקר.

כל השעות ודרישות האיוש נמצאות בקובץ `config/oncology.json` ולא מקודדות במנוע.
